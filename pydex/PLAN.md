# Pydex — plan

**What it is.** A static, zero-build, interactive reference for the most-used
Python libraries. Every library gets a cheat sheet you can run, animated
explainers for the ideas people trip on, comparison tables, and a sandbox with
mock data. Lives at `pydex/` in this repo like its sibling `atlas/`; deploys as
plain files (GitHub Pages, Netlify, `python3 -m http.server`).

## Scope (v1)

| Group | Libraries |
|---|---|
| Data | numpy, pandas, polars, matplotlib, scikit-learn |
| Web | requests, beautifulsoup4, fastapi |
| Correctness | pydantic, pytest |
| Storage | sqlalchemy |
| Concurrency | asyncio |

Each library page has the same five parts, in this order:

1. **Overview** — one paragraph, install line, "reach for it when / not when".
2. **Cheat sheet** — grouped snippets. Every snippet has a Run button
   (inline output), Copy, and Open in sandbox.
3. **Concepts, animated** — one or two step-through explainers
   (play / pause / step / scrub; honours `prefers-reduced-motion`).
4. **Compare** — tables inside the library (e.g. `loc` vs `iloc`) and a link to
   the cross-library charts.
5. **Gotchas** — short, concrete, with the fix.

Cross-library **Compare** page: feature matrices and rating charts
(pandas / polars / numpy, requests / httpx / urllib, pytest / unittest,
pydantic / dataclasses / attrs, fastapi / flask / django, sqlalchemy core /
ORM / sqlite3, asyncio / threading / multiprocessing). Ratings are
qualitative (1–5 dots) and features are yes/no; no invented benchmarks.

## Sandbox

- Real CPython in the browser via **Pyodide** (loaded from jsdelivr on first
  Run, in a Web Worker so the page never freezes).
- Packages load on demand per snippet (`numpy`, `pandas`, `matplotlib`, …).
- Mock data mounted at `/data`: `orders.csv`, `employees.csv`,
  `products.json`, `page.html`, and `shop.sqlite` built at start.
- `requests` is patched to serve `https://api.pydex.local/…` from the mock
  data, so HTTP examples run offline. `httpx` gets a `MockTransport`.
- Jupyter-style: the last expression is displayed; DataFrames render as
  tables; matplotlib figures render as images.
- FastAPI is documented but not runnable in the browser; its snippets say so.

## Design system

- **Palette** — ground is a cool slate (light `#F4F6F8`, dark `#0F141A`), ink
  `#171C23` / `#E6EAF0`, accent *amber* `#B7791F` on light / `#E8A93A` on dark
  (Python's yellow, matured), semantic green `#2E9E6B`, rose `#D4483B`,
  blue `#2F6FDB` for notes. Neutrals lean toward the slate hue.
- **Type** — Bricolage Grotesque (display, tight tracking), Source Sans 3
  (body), JetBrains Mono (code, tabular numerals).
- **Layout** — app shell: left library rail, content column ~72ch, right
  in-page nav on wide screens; hash routes (`#/lib/pandas`, `#/compare`,
  `#/sandbox`) so deep links work on static hosts. Command palette (⌘K).
- **Motion** — explainers are state machines: each step sets classes and CSS
  transitions do the movement; nothing animates width/height. Reduced-motion
  users get instant steps.
- **Accessibility** — 4.5:1 contrast on both themes, visible focus, keyboard
  navigation for palette and explainers, labelled icon buttons, 44px targets.

## Files

```
pydex/
  index.html            shell
  css/pydex.css         tokens + components
  js/app.js             router, shell, search, theme
  js/pages.js           home / library / compare / sandbox renderers
  js/highlight.js       small Python tokenizer → spans (no dependency)
  js/explainer.js       step-through animation engine
  js/compare.js         matrix / rating renderers
  js/sandbox.js         Pyodide client + output rendering
  js/sandbox-worker.js  Pyodide worker: FS mounts, mocks, run protocol
  data/libs/*.js        one module per library (content)
  data/comparisons.js   cross-library matrices
  data/mock/*           committed mock datasets (generated by tools/)
  tools/make-mock-data.py
```
